## Context
Claude Code가 남기는 데이터(대화 기록, 파일 이력)와 hook이 남기는 데이터(세션 상태, 관측 기록)는 조용히 쌓인다. 세션 상태 파일은 아무도 모르는 사이 3만 개가 넘었고(P0-13에서 발견), 그때까지 크기를 알려 주는 장치가 없었다. 세션이 끝날 때 주요 폴더의 크기를 재서 적어 두고, 기준을 넘으면 다음 세션 시작 때 한 줄로 알린다. **삭제는 하지 않는다.**

## 확인한 사실 (2026-11-15 측정)
- `~/.claude/projects` 193개 파일 471MB(걷는 데 0.05초), `~/.claude/file-history` 2,307개 40MB(0.5초), 임시 폴더의 `claude-discipline` 약 37,000개, 디스크 여유 272GB / 1,023GB.
- Claude Code는 `cleanupPeriodDays`(기본 30일) 뒤 `projects/`의 대화 기록, file-history 등을 스스로 지운다(`tests/_baseline/2026-11-11-p0-02.md` 7번). `settings.json`에 이 값을 따로 정하지 않았다(기본값 30일).
- 세션 종료 hook(`hooks/handoff.py end`, 제한 5초, 내부 예산 3초)은 종료 기록을 쓰고 오래된 세션 상태를 정리한다(P0-13). 세션 시작 hook(`hooks/session_context.py`)은 안내 줄을 한도 안에서 합친다.
- hook이 만드는 관측 기록(`authz-observe`, `review-observe`, `test-gap-observe`, `output-size-observe`)은 승인 저장소 폴더에 있고 크기 상한이 없다. 그 폴더는 도구로 읽지 못하게 막혀 있지만 hook은 크기를 잴 수 있다.

## 설계
### 1. 새 모듈 `hooks/usage.py`
- `measure(folder, budget_s, clock) -> {files, bytes, partial}`: 폴더를 걸으며 파일 수와 크기 합을 낸다. 링크는 따라가지 않는다. 예산을 넘으면 그때까지의 값과 `partial: true`를 돌려준다. 없는 폴더는 0.
- `snapshot(now, budget_s) -> dict`: 아래 대상을 차례로 재고 디스크 여유 공간을 더한다(전체 예산 1초).
  - `projects`(대화 기록), `file-history`, `state`(종료 기록·원장), 임시 폴더의 `claude-discipline`(세션 상태), 승인 저장소 폴더(관측 기록 — 파일 수와 크기 합만, 이름·내용은 보지 않는다).
- `write(snapshot)` / `read()`: `~/.claude/state/usage.json`(환경 변수 `CLAUDE_USAGE_FILE`로 변경 가능, 테스트용). 허용 목록의 키만 쓴다.
- 순수 함수 `warnings(snapshot, limits) -> list[str]`: 기준을 넘은 항목마다 한 줄. 초기 기준(실측 뒤 다시 정한다): `projects` 2,000MB, `file-history` 500MB, 세션 상태 100,000개, 관측 기록 50MB, 디스크 여유 20GB 미만. 측정이 14일보다 오래됐으면 경고하지 않는다.

### 2. 연결
- `handoff.py end`: 종료 기록과 상태 정리 뒤, 남은 시간이 충분하면(시작 후 2초 이내) `usage.snapshot`을 재서 쓴다. 실패는 stderr 한 줄, 종료 코드는 0.
- `session_context.py`: 세션 시작(`SessionStart` 이벤트, 요약 뒤 재개 제외) 때 `usage.read()`와 `warnings`로 경고 줄을 만들어 안내 줄 맨 뒤에 붙인다. 기준 안이면 아무 줄도 없다.

### 3. 보존 정책 문서
- `docs/retention.md`를 새로 쓴다: 무엇이 어디에 쌓이는지, 누가 언제 지우는지(Claude Code의 `cleanupPeriodDays` 30일, P0-13의 35일 정리), 지워지지 않는 것(원장, 관측 기록, 복구용 사본, 비워진 `.notes` 폴더), 경고 기준과 조정 방법. 사실은 이 저장소의 코드와 P0-02 문서에서 확인된 것만 적고, 확인하지 못한 것은 미확인으로 적는다.

### 검토한 대안

| B. 세션 시작 때 잰다 | 기각: 시작 hook에 폴더 탐색(지금 0.5초, 커지면 더)을 넣게 된다 |
