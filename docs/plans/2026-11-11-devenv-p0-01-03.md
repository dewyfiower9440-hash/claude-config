## 설계 (P0-03 최소 수정)
`rearm_approval(cwd, prompt)`를 다음처럼 바꿉니다.
1. **root**: cwd의 git toplevel(`worktree.toplevel`)을 쓰고, 저장소가 아니면 cwd 자신을 씁니다. `root/docs/plans`만 탐색하고 상위로는 올라가지 않습니다.
2. **명시 신호** `prompt_refs(prompt)`: 프롬프트 안의 `task:<id>`, `task_id: <id>`, `task=<id>` 토큰과, 계획 파일 basename(`2026-..-x.md`)의 등장을 찾습니다. 명시 신호가 없으면 재무장하지 않고, 재무장할 수 있는 계획이 있을 때만 "task:<id>를 명시하세요"라고 경고합니다.
3. **후보**: in-progress, 미체크 항목 존재, 프롬프트가 지목한 task 또는 파일, 서명·만료 검증 통과, `record.base == root`(normcase 기준 동일)를 모두 만족해야 합니다.
4. 후보가 정확히 1개면 재무장합니다. 2개 이상이면 재무장하지 않고 모호하다고 경고합니다.
5. `on_prompt`는 `data["prompt"]`를 넘깁니다(필드명은 P0-02에서 공식 문서로 확인). 같은 프롬프트 안에서 ExitPlanMode로 받은 승인은 지금처럼 그 프롬프트에만 유효합니다.
